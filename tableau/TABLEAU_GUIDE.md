# 항공 승객 만족도 Tableau 대시보드 제작 가이드

PPT(항공_만족도_분석_포트폴리오.pptx)와 같은 수치를 쓰는 대시보드 3개를 만드는 순서.
Tableau Desktop에서 아래 CSV를 연결하면 됨 (텍스트 파일 → UTF-8 자동 인식).

## 0. 데이터 파일 (이 폴더)

| 파일 | 행 수 | 용도 |
|---|---|---|
| `service_lift_all.csv` | 9 | 서비스 9개의 "4점 이상 개선 시 전체 비행 만족률 상승폭(%p)" 순위 (PPT 10번) |
| `lift_table.csv` | 30 | 승객군(전체/출장/개인 여행/충성/비충성) × 서비스 × 상승폭 (PPT 11번, 시뮬레이터) |
| `service_score_summary.csv` | 1,008 | 여행 목적 × 고객 유형 × 좌석 등급 × 서비스 × 점수별 승객 수·만족 승객 수 (EDA) |
| `passengers.csv` | 103,904 | 승객 단위 원본(한글 라벨). 용량 문제로 저장소에서 제외, `code/04_tableau_data.py` 실행 시 생성 (선택) |

- 상승폭 = 해당 서비스를 4점 미만 → 4점 이상으로 올렸을 때(전원 개선 가정) 전체 비행 만족률이 오르는 %p. 로지스틱 회귀 기반 추정.
- `lift_table.csv`의 "와이파이 + 온라인 탑승", "상위 4개 전체"는 여러 서비스를 동시에 올린 값 (단순 합이 아님). 이론상 최대치에 가까운 외삽 값이므로 해석 주의.

## 1. 대시보드 ① 핵심 결과

**시트 A. 서비스별 효과 순위** (`service_lift_all.csv`)
- 행: `서비스` (내림차순 정렬) / 열: `SUM(전원 개선 시 상승폭(%p))` / 라벨: 값
- 색: 상위 2개만 주황, 나머지 회색 → 계산 필드 `상위 여부` = `[순위] <= 2`

**시트 B. 승객 유형별 비교** (`lift_table.csv`)
- 필터: `승객군` = 출장, 개인 여행 / `서비스` = 기내 와이파이, 온라인 탑승, 체크인
- 열: `서비스` / 행: `MAX([전원 개선 시 상승폭(%p)])` / 색: `승객군` / 막대 라벨 표시

**시트 C. 현황 KPI** (`service_score_summary.csv`)
- 필터: `서비스` = 기내 와이파이 (모든 승객이 한 번씩만 집계되도록 서비스 1개로 고정)
- 계산 필드 `전체 비행 만족률` = `SUM([만족 승객 수]) / SUM([승객 수])` → 텍스트 시트 (약 43%)

배치: 위에 KPI(C), 왼쪽 A, 오른쪽 B. 제목은 "와이파이·온라인 탑승 개선 효과가 가장 큼".

## 2. 대시보드 ② 시뮬레이터 (`lift_table.csv`)

**파라미터 3개** (데이터 창 우클릭 → 파라미터 만들기)

| 이름 | 데이터 유형 | 허용 값 |
|---|---|---|
| `승객군 선택` | 문자열 | 목록: 전체, 출장, 개인 여행, 충성, 비충성 |
| `서비스 선택` | 문자열 | 목록: 기내 와이파이, 온라인 탑승, 체크인, 다리 공간, 와이파이 + 온라인 탑승, 상위 4개 전체 |
| `개선 비율(%)` | 정수 | 범위 0~100, 단계 10 |

**계산 필드**
```
선택 조건      : [승객군] = [승객군 선택] AND [서비스] = [서비스 선택]
현재 만족률    : MAX([기준 만족률(%)])
예상 상승폭    : MAX([전원 개선 시 상승폭(%p)]) * [개선 비율(%)] / 100
예상 만족률    : [현재 만족률] + [예상 상승폭]
```
- `선택 조건` = True 로 필터링하면 행이 1개만 남음.
- "개선 비율" = 현재 4점 미만인 승객 중 4점 이상으로 올라가는 승객의 비율. 무작위로 그 비율만 개선된다고 보면 기대 상승폭은 비율에 비례하므로 위 식이 성립.

**시트 구성**: 텍스트 시트 3개(현재 / 예상 상승폭 / 예상 만족률) + 막대 1개(현재 vs 예상, 측정값 이름/값 사용).
파라미터 컨트롤 3개를 오른쪽에 표시. 예) 개인 여행 + 기내 와이파이 + 100% → 10.2% → 40.2%.
주의: 개인 여행에서 온라인 탑승·체크인은 0%p로 나오는 것이 정상 (분석 결과).

## 3. 대시보드 ③ EDA 탐색 (`service_score_summary.csv`)

**필터 3개(전체 시트에 적용)**: `여행 목적`, `고객 유형`, `좌석 등급` → 필터 우클릭 → "관련 워크시트에 적용"

**계산 필드**
```
만족률       : SUM([만족 승객 수]) / SUM([승객 수])
점수 구분    : IF [점수] >= 4 THEN '4점 이상'
               ELSEIF [점수] >= 1 THEN '4점 미만'
               ELSE '해당없음(0점)' END
```

**시트 D. 점수별 만족률**: 필터 `서비스` 단일 선택(드롭다운) / 열 `점수` / 행 `만족률` / 색 `점수 구분` → 3점→4점에서 급증하는 모양 (PPT 7번)
**시트 E. 서비스 × 점수 히트맵**: 행 `서비스` / 열 `점수` / 색 `만족률` / 텍스트 `SUM([승객 수])`
**시트 F. 승객 유형별 만족률**: 서비스 필터를 기내 와이파이로 고정, 열 `여행 목적`(또는 고객 유형, 좌석 등급) / 행 `만족률`

## 4. 참고
- 수치는 PPT와 동일하게 `random_state=42`, 80/20 분할로 학습한 로지스틱 회귀 기준. 전체 승객군 상승폭은 검증 데이터(20%), 승객군별은 해당 승객군 전체 데이터로 추정.
- 데이터 출처: Kaggle 항공 승객 만족도 설문 (103,904명). 대시보드에도 출처를 표기할 것.
